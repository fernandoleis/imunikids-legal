# Site jurídico mínimo do ImuniKids

Arquivos prontos para publicação estática:

- `index.html`
- `privacidade.html`
- `termos.html`
- `excluir-conta.html`
- `suporte.html`
- `styles.css`

## Publicação rápida no GitHub Pages

1. Crie um repositório público, por exemplo `imunikids-legal`.
2. Copie todos os arquivos deste diretório para a raiz do repositório.
3. Faça commit e push.
4. No GitHub, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a URL pública.

Use na Play Console:

- Política de privacidade: `https://SEU-USUARIO.github.io/imunikids-legal/privacidade.html`
- Exclusão de conta: `https://SEU-USUARIO.github.io/imunikids-legal/excluir-conta.html`

## Pendência obrigatória antes da produção

O aplicativo ainda precisa oferecer um caminho interno destacado para solicitar/executar a exclusão da conta, por exemplo:

`Configurações → Minha conta → Excluir conta`

A página Web já permite iniciar a solicitação por e-mail, mas não substitui o caminho dentro do aplicativo exigido para apps com criação de conta.

## Revisão

Este material é uma base prática para publicação e deve ser revisado sempre que o aplicativo, os fornecedores, a coleta de dados ou a monetização mudarem. Não substitui assessoria jurídica individual.
